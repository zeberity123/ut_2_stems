UT Stems Client
===============

The same window as UT Stems, but the songs are separated on another PC: the one that runs
UT Stems Server (ut_stems_server.bat). This PC needs no graphics card and no setup.

1. Start "UT Stems Client.exe".
2. A server on the same network shows up by itself; press Connect.
   From elsewhere (home, another office), type the server's address once, for example
   210.96.103.95. It is shown in the server's window and remembered.
3. The server PC asks whether to let this PC in, with a four-digit code. Check that the
   code matches the one on this screen and press Yes there. This is needed only once.

Then add YouTube links or files as usual. Files are sent to the server, and the finished
stems are saved in the output folder on this PC.

- "on <server> x" at the top right disconnects from the server.
- If the server PC says this PC is no longer registered, register again the same way.
- The connection is encrypted, and this PC only accepts the server it first registered with.
